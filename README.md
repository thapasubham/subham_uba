# UBA Internship

This repo is for my internship project

## Project Setup

- Clone this Repo

```
git clone https://github.com/thapasubham/subham_uba.git
```

- Navigate to the project directory

```
cd subham_uba
```
- Add a new .env file and follow as in the .env.example file

- Install the dependencies

```
npm install
```

- Run the projects

```
npm run start
```
## You can also run this on docker
```
docker compose up
```
